# LinguaNote — инструкция по запуску

Сайт с настоящими аккаунтами (логин + пароль) для преподавателя и студентов.
Всё бесплатно на старте. Займёт ~20-30 минут, кода писать не нужно.

## Шаг 1. Создать базу данных (Supabase)

1. Зайди на **supabase.com** → **Start your project** → зарегистрируйся (можно через GitHub или email).
2. Нажми **New project**. Придумай имя (например `linguanote`) и пароль базы данных (сохрани его куда-нибудь).
3. Подожди 1-2 минуты, пока проект создастся.
4. Слева в меню открой **Authentication → Providers → Email** и **отключи** пункт "Confirm email" (это упростит регистрацию на старте — подтверждение почты можно включить позже).
   Также: **Authentication → Settings** — там же можно выключить подтверждение, если не нашёл в Providers.
5. Слева открой **SQL Editor → New query**.
6. Открой файл `schema.sql` из этой папки, скопируй весь текст и вставь в редактор.
7. Нажми **Run**. Должно появиться "Success. No rows returned" — значит таблицы созданы.

## Шаг 2. Подключить сайт к базе

1. В Supabase слева: **Project Settings → API**.
2. Скопируй **Project URL** и **anon public** ключ.
3. Открой файл `config.js` из этой папки и вставь туда:
   ```js
   window.SUPABASE_URL = "https://xxxxx.supabase.co";
   window.SUPABASE_ANON_KEY = "eyJhbGciOi...";
   ```
4. Сохрани файл.

## Шаг 3. Опубликовать сайт (бесплатно, без кода)

Самый простой способ — **Netlify Drop**:

1. Зайди на **app.netlify.com/drop**
2. Перетащи мышкой всю папку `linguanote-web` (с файлами `index.html`, `config.js`) в окно браузера.
3. Через несколько секунд получишь рабочую ссылку вида `https://random-name-123.netlify.app` — это уже готовый сайт.
4. (Необязательно) в настройках Netlify можно переименовать адрес или подключить свой домен.

## Шаг 4. Проверить

1. Открой ссылку на сайт → вкладка "Я преподаватель" → "Зарегистрироваться" → создай свой аккаунт.
2. Нажми "+" внизу справа → добавь студента → скопируй код приглашения.
3. Открой сайт в другой вкладке (или отправь ссылку студенту) → "Я студент" → "Зарегистрироваться" → ввести код.
4. В аккаунте преподавателя открой студента → "Начать урок" → потыкай Grammar/Pronunciation/Vocabulary → "Завершить урок".
5. Зайди под студентом — там должна появиться история урока и статистика.

## Как это устроено (коротко)

- Пароли и авторизация полностью на стороне Supabase — сайт их не хранит.
- Row Level Security (RLS) в базе физически не позволяет одному студенту увидеть данные другого — это не просто скрыто в интерфейсе, а запрещено на уровне базы данных.
- Бесплатный тариф Supabase: до 50 000 активных пользователей в месяц, 500 МБ базы данных — для практики с учениками более чем достаточно.
- Netlify бесплатный тариф: 100 ГБ трафика в месяц — тоже с большим запасом.

## Что можно добавить дальше

- Расписание занятий (calendar)
- Экспорт отчёта по студенту в PDF
- Push-напоминания о занятии
- Смена пароля / восстановление пароля (Supabase это умеет "из коробки", просто пока не подключено в интерфейсе)

Если что-то не заработает на каком-то шаге — пришли скриншот ошибки, разберёмся.
